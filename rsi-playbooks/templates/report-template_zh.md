# 优化结果汇报

[English](report-template.md) | 简体中文

持续维护同一份 `report.md`。指定的总览负责人在任务级 `.foretoken-report.lock` 下维护元数据、状态和简短解释。Experimenter 更新自己迭代的记录并刷新生成进展视图；不要把数值行复制进本文件。

## 任务

| 字段 | 内容 |
| --- | --- |
| 目标 | 模型、优化目标和决定范围 |
| 负载 | 请求协议、输入／输出预算和并发级别 |
| 状态／更新时间 | 运行、暂停或完成；ISO 时间与观察来源 |
| 总览负责人 | 负责报告文字的原生成员身份；更换时记录接替者和交接时间 |
| 预算 | 原始起点、硬截止和资源上限 |
| 任务／结果 | 任务文件和结果目录链接 |
| 剩余验证／清理 | 未完成的质量或性能检查，以及实际资源退出证据 |

## 生成的进展

在此链接 `figures/progress/progress-summary.md` 及对应图表。生成摘要是数值唯一来源：它保留用户最初 baseline、实测父版本、限定范围的比较、采用／弃用／待验证方案和失败尝试。生成视图分开记录并发级别和负载协议时，报告也保持分开。

## 各方案

使用与生成摘要相同的名称。总览负责人保持每段简短；完整测量、命令、日志、输出检查、独立审查和决定历史留在链接的迭代记录中。

### 方案 A

说明瓶颈、实际父版本、实现增量和决定范围。链接迭代记录及源码／配置证据。

### 方案 A + B

说明 B 在已采用 A 上增加了什么，以及组合实测得出了什么结论。独立的 A、B 实验不能代表 A+B；组合配置需要自己的实测记录。

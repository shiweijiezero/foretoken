# 参考模板

[English](README.md) | 简体中文

- [优化任务](task-template_zh.md)：模型、单服务配置、可用资源、负载、目标与工作条件。
- [用户汇报](report-template_zh.md)：面向未参与实验的读者，展示逐轮改动、任务指标实测值、相对 base 的变化和结论。
- [进展图数据](progress-template.yaml)：累计里程碑和搜索历史，使用方法见[绘图指南](progress-charts_zh.md)。
- [迭代说明](iteration-template_zh.md)：一轮方案的分析、设计、改动、测量和决策。
- [知识条目](guidance-template_zh.md)：技术原理、发现、工作经验、适用条件、依据，以及可复用的实现与实验入口。

实验目录和记录方法见[实验记录手册](../experiment-records_zh.md)。

# 本轮迭代说明

[English](iteration-template.md) | 简体中文

编写 `results/<goal>/<motivation>/iterations/<name>/notes/iteration.md` 时参考。注明开发者、执行者、记录作者和独立审查者，引用本轮 `../runs/` 中的证据。按[记录手册](../experiment-records_zh.md#完善实验说明)保留分析、审查和决策的演进过程。

负责人和调度安排链接已有任务记录；没有任务工具时，在这里记录当前负责人、依赖、资源分配和测量时段。

## 摘要与完整文档

每项内容填写简短摘要，链接本 `notes/` 目录中的完整文件，例如 `plan.md` 或 `analysis.md`。下方各节保留简要结论及审查、决策历史，完整解释在所链接的文件中展开。

## 问题与分析

概述本轮问题，链接完整分析及其使用的代码、观察、已有结果和参考资料。

## 假设与设计

概述 Worker 提出的改进与预期有效的机制，链接完整方案及实现、验证计划，记录主 Agent 围绕假设选择的对照。

## 实现与部署

概述 Worker 交付的改动，链接 checkout、版本或改动文件及完整说明。记录执行者实际构建部署的版本、环境和配置，以及与设计的重要差异，注明执行期间保持不变的工作区。

## 测量与解释

按运行名称追加简要结论，链接 `../runs/<run>/` 中的结果和完整分析，说明假设是否得到支持，以及失败或中断对结论的影响。负载和样本量的选择依据、对照数据及差异成因在所链接的分析文件中展开。

## 时间花费

记录调查、设计、实现、部署、评测和分析的耗时，实测值引用记录，估算值注明来源。包含关系的时间分别说明。

## 行为与归因复核

追加注明时间和独立审查者的检查结果，涵盖测试取巧、模型行为、对照条件和收益来源。链接完整复核与原始证据，说明哪些结论有依据、哪些需要补测。后续更正引用原条目，不覆盖之前的判断。

## 决策与收尾

按时间追加决定，注明来源和支撑证据，区分 Worker 对实验候选的处理结果与主 Agent 的保留或集成决定。写清行动、范围、实际代码与部署状态，以及下一轮仍需使用的资源。决定变化时追加新条目，指出替代的是哪个旧决定，保留原判断及其依据。

# 元知识

[English](README.md) | 简体中文

帮助 Agent 自主研究和改进推理系统的方法。编号提供阅读顺序，实际工作中按问题选用。

1. [寻找参考资料](01-reference-search_zh.md)：了解现状、拓展思路，为自己的研究寻找启发。
2. [定位瓶颈](02-bottleneck-analysis_zh.md)：结合测量、剖析、源码与局部实验解释性能问题。
3. [探索与决策](03-exploration-and-decision_zh.md)：选择有价值的问题，持续深入研究与改进。
4. [架构与方法设计](04-architecture-and-design_zh.md)：比较算子、引擎、请求服务和集群编排等层次的实现方案。
5. [记录与学习](05-recording-and-learning_zh.md)：积累发现、低效经验和可复用的实验入口，供后续工作使用。
6. [帕累托引导探索（PGE）](06-opportunity-assessment_zh.md)：量化收益、可行性、证据和成本，供 Evaluator 评估、主 Agent 决策。

具体技术原理与发现见[知识库](../knowledge/README_zh.md)。

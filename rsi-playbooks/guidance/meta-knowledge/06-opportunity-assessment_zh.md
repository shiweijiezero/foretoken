# 06｜帕累托引导探索（PGE）

[English](06-opportunity-assessment.md) | 简体中文

帕累托引导探索（Pareto-Guided Exploration，PGE）通过机会评估、前沿识别、主 Agent 决策和实验反馈，组织 Agent 的推理优化工作。

PGE 优先攻重要且有大幅改善潜力的问题，目的是发现并实现更好的机制，包括算法、算子、数据流和执行架构的深度改造。主 Agent 围绕这些机会组织持续研究，小改进和独立备选方向可以并行。Evaluator 评估证据与实际投入，未来选择由主 Agent 作出；两者沿用已有评估与团队记录。

## 先组织研究，再比较候选

先理解哪些限制对任务最重要，以及什么机制可能改变它们。Explorer 探索当前候选清单之外的思路；主 Agent 选择主攻问题，让负责人有时间推进核心实现，并安排能够回答主要未知的实验。快速改进也有价值，但就绪更早或成本更低，不使它天然优先于更重要的工作。

机会前沿比较的是当前能比较的候选，不是值得研究方向的边界。新机制可能尚无收益估计或完整集成方案，应写明问题的重要性、所考虑的机制和关键未知，不编造乐观数字，也不把 `U` 当低价值。在这些估计出现之前，主 Agent 就可以投入研究和原型实现。选择考虑整条研究路线的价值，而不只看下一次实验的单位时间收益。

例如，下列假想研究问题处于不同阶段，不应放进同一张收益／成本排行榜：

| 研究问题 | 已有证据 | 关键未知 | 研究可能产生的信息 |
| --- | --- | --- | --- |
| 改变数据布局能否消除重复物化？ | 中间拷贝占据已观察路径的重要部分 | 下游能否直接消费新布局，而不引入转换成本 | 可运行的核心路径，以及节省与新增流量的解释 |
| 重组执行能否重叠当前暴露的阶段？ | Profile 存在等待与部分串行执行 | 哪些依赖是必要的，哪些来自当前实现 | 因果依赖模型与可执行的替代调度 |
| 改变推测机制能否降低每个接受 token 的成本？ | 已记录各负载的草稿与验证成本 | 改动能否减少总工作量，而非只提高接受率 | 解释或原型，澄清联合成本取舍 |

这些例子说明可能的研究产出，不是 Evaluator 派工或收益承诺。有价值的阶段可以先建立机制解释、发现限制或交付核心实现，再得到服务净收益。原型变慢或失败时，应分析思路及其实现，而不是立即否定整个方向。

按研究问题与版本归并测量，保留负载、参照、阶段、原件和负责人给出的剩余工作估计。未知记 `U`，不适用记 `N/A`。根据已有证据更新变化项，不为填评分而额外测量。质量验证按输出影响和任务约定执行，最终保留遵循任务的正确性、精度与资源要求。

## 区分实测与研究机会

实测部署前沿在任务正确性与质量要求下比较已测性能和资源消耗。仍适用的历史证据可以支持这些要求，无需每次测速后重新评分。尚未明确的输出影响与速度结果一起记录，暂不当作已确认的部署收益。

研究机会前沿比较已记录方向的预期收益与新增成本。保留任务原始 baseline，同一比较采用共同参照和指标定义，硬件或协议不兼容时分组。相对原型的剩余收益与相对共同参照的总收益分开。多个必需负载保留收益向量，避免改善遮住回退；只有任务指定权重时才汇总。

估计注明作者、时间、假设、来源与范围。区分实测波动、统计区间和工程上下界；测量区间重叠时，仅凭均值不能确认改善。

## 描述收益、证据与成本

先列原始数值，再用以下 0–4 分概括。分数用于讨论，不是概率或采用门槛；数值跨档时给出分数范围。同一任务沿用相同尺度；主 Agent 调整尺度时，先说明原因，再统一比较重新评分的条目。

### 收益与上限：G

吞吐提升为 `100 × (候选 / 参照 − 1)`%，延迟下降为 `100 × (1 − 候选 / 参照)`%。保留负值、输出长度与波动，实测和预测分别标识。只有理想上限时，不能据此填预期值或下界。

| G | 每项必需指标的收益 |
| --- | --- |
| 0 | 零或负值，保留实际带符号数值 |
| 1 | 大于 0%、小于 5% |
| 2 | 至少 5%、小于 10% |
| 3 | 至少 10%、小于 20% |
| 4 | 至少 20% |

根据相关关键路径估算上限。组件占总耗时比例为 `f`，局部加速倍数为 `s`，新增开销占原耗时比例为 `a` 时，简化加速比为 `S = 1 / (1 − f + f/s + a)`。固定工作量下，吞吐提升为 `100 × (S − 1)`%，耗时下降为 `100 × (1 − 1/S)`%。完全消除占总耗时 4% 的组件，吞吐最多提升 4.17%；该组件加速 2 倍，整体提升 2.04%。重叠的 GPU kernel 时间不能累加成 `f`，延迟节省也不必然成为服务吞吐提升。

### 可行性 F、证据 E 与信息 I

F 评估机制在任务语义、精度、硬件和资源约束下的可行性，与环境就绪程度分开。E 支持某项明确结论：证据充分的负结果可以是 E4、G0。I 描述本观察期实际获得的信息，与负责人预期的未来信息价值分开。

| 分数 | F：机制可行性 | E：所述结论的证据 | I：已获得的信息 |
| --- | --- | --- | --- |
| 0 | 违反必要不变量或已证上限 | 尚无支撑证据 | 重复已知事实 |
| 1 | 机制已描述，关键假设未解决 | 理论、源码或其他条件的结果 | 复现症状或核对就绪状态 |
| 2 | 分析支持路径，仍有集成假设 | 局部对照或组件测量 | 区分一个解释或建立有用上限 |
| 3 | 在任务约束内核算了依赖与新增成本 | 匹配服务对照，复现或覆盖尚不完整 | 解决关键因果或正确性问题 |
| 4 | 代表性执行验证机制与必要不变量 | 重复且有代表性的对照支持所述范围 | 经独立检查并在相关场景复用的发现 |

链接证据、适用范围和未解假设。较低的 F 或 E 可以指出深入研究要解决什么，不使有依据的重要问题变得次要。区分当前原型的表现与不同实现可能打开的空间。E 包括已有且仍适用的正确性证据。代码量、消息和 PR 数量不代表 I。

### 新增成本：C

已付成本用于反思，新增成本用于决策。记录墙钟小时、实际归属本任务的 GPU 小时和 Agent 工作小时；证据允许时分开准备与等待。并行墙钟不能相加，开放回合也不等于已测有效工作。token 或金额成本需有可靠归属。

成本比较采用相同证据里程碑。组件探针与完整服务验证产出不同；能估计时先估下一研究阶段的投入，集成成本尚不明确则保留 U，随实现逐步更新。完整交付估时不是启动重要研究问题的前提。

对应资源的剩余预算 `B > 0` 时，按新增成本 `c` 的比例 `r = c/B` 给分。预算已用尽时，正的新增成本为 C0，无新增成本为 C4。同一快照各行采用相同时间与预算。跨轮保留原始成本：预算缩小可以使 C 降低，但不说明方法本身变得低效。

| C（越高表示成本越小） | 占剩余预算的比例 |
| --- | --- |
| 4 | `0 ≤ r ≤ 0.05` |
| 3 | `0.05 < r ≤ 0.15` |
| 2 | `0.15 < r ≤ 0.35` |
| 1 | `0.35 < r ≤ 1` |
| 0 | `r > 1` |

有预算时分别给出 `C_time`、`C_gpu`、`C_agent`；无预算则保留原始成本，C 记 `U`。墙钟预算截止于任务期限，GPU 与 Agent 预算采用实际可用额度。未知成本为 U，与已知超预算的 C0 分开。

## 单独评估环境工作

环境工作只有实测推理性能变化才填写推理 G。其赋能价值记为 `U_env`：0，没有已记录消费者；1，便利性或未证实的延误改善；2，实测准备时间节省；3，解除已记录实验的真实阻塞；4，经验证的修复解锁多个实验或防止已复现的反复故障。

净累计准备时间节省估计为 `N × 每次节省 − 剩余修复及验证时间`，N 只计剩余任务内可能执行的次数，计入部署成本。节省位于串行关键路径时才等于任务墙钟节省，准备重叠时结合排期估算。GPU 与 Agent 成本另列。修复使原本不能执行的实验变得可行时，直接指出该实验，不虚构节省分钟数。同一项推理收益只归因一次。

Evaluator 报告本期和任务累计的时间分配、覆盖范围与被延误的工作。环境投入增加但就绪程度未改善时，提醒主 Agent 判断，不设置自动比例上限。

## 判断非支配机会

帕累托支配指所有比较目标都不差、至少一个严格更好。按主 Agent 确定的共同负载、里程碑和资源范围，比较原始收益向量与新增成本。F、E、I 随比较展示，不相加或相乘生成优先级或成功概率。

使用上下界时，只有 A 每项收益的下界都不低于 B 的上界，且 A 每项成本的上界都不高于 B 的下界，并有一项严格更好，才称 A 稳健支配 B。结论以所列上下界和假设为准；否则支配关系待定，未知值或不兼容条件也不能判支配。粗评分相同不代表原始数值相同。

作为纯数值例子，两条通向同一验证里程碑的实现路径使用共同参照：A 的收益范围为 4–6%、新增成本为 3–4 小时；B 为 8–10%、1–2 小时。给定这些假设，B 支配 A。这只是对这些实现和估计的比较，不代表 A 背后的机制在其他实现下也没有价值。

已证实违反约束的候选保留反证，排除在可行候选前沿外；可行性未明时保留未知。极便宜的 1% 改善可以非支配，但未必是最值得投入的研究。因此 Evaluator 还要检查：重要机制是否有人持续研究、是否实际获得实现时间与实验机会，还是团队都集中在小而就绪的改动、报告或环境工作上。它报告进展与被忽视的机会，不指定下一方向。

主 Agent 据此选择或调整研究组合：主攻问题、独立备选、并行的小改进、负责人、阶段预算，以及预期认识或实现产出。证据形成期间保持重要问题的连续投入，不因另一个便宜实验先结束就改派其负责人。证据削弱潜力或后续投入不再值得时，再考虑转向；这与原型尚未完整或暂时变慢分开判断。后续评估对照这些决定核查实际投入与进展。

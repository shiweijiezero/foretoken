# 优化指导

[English](README.md) | 简体中文

结合研究方法与技术知识了解系统现状，提出自己的设计，并从实验中持续学习。

- [元知识](meta-knowledge/README_zh.md)：寻找资料、定位瓶颈、选择研究方向、设计改进与记录经验。
- [技术知识](knowledge/README_zh.md)：自包含地解释现象、机制、设计、实现与效果，注明适用条件和证据。

从知识总索引按当前问题选读，条目用于理解和比较方法，不指定优化方向。用新的研究与实验结果补充、修正知识。命令和实验产物的用法见[实验记录手册](../experiment-records_zh.md)。

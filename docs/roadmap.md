# 路线图

按功能方向组织(非时间表)。北极星指标是 ¥/Mtok@SLO;每个优化方向都以真实负载 goodput 评测为裁判,在「完成」前需通过一个对标基线的可证伪门槛。

## 评测台(已有)

- 闭环回放真实会话负载(真实 timestamp、会话化、现场生成拼接下一轮)。
- goodput@SLO 阶梯、¥/Mtok@SLO、延迟分位、吞吐、引擎 KV/并发监控。
- 三种后端形式(进程内 / 外部 endpoint / 自起 serve),后端无关。
- 多组对比、负载扫描曲线、双语图、排行榜。

## 价值感知 KV 管理

vLLM 等引擎的前缀缓存默认按近因(LRU)驱逐,不感知复用价值、重算成本与 SLO。方向:以「每 GPU 字节秒的期望 goodput」为目标,做价值/复用/SLO 感知的准入、驱逐与卸载(跨 GPU→CPU→NVMe 各层),面向长生命周期复用。门槛:在受限容量(工作集 > 容量)区间,goodput / 每字节 goodput 胜过 LRU 基线,且无损校验通过。

## 自适应投机解码

投机解码(含目标模型自带的 MTP 层)在低负载、长上下文下加速明显,在高并发、短上下文下可能转负。方向:按观测到的接受率与负载动态调整投机长度(goodput 感知),而非静态配置。详见[投机解码 MTP](mtp.md)。

## goodput 感知调度

把 goodput 作为准入、排序、批选择的统一标尺;在 KV 压力与并发下做 SLO 感知的调度决策。

## 多节点与分离式部署

规模到了之后:KV-aware 路由、prefill/decode 分离、按 SLA 自动扩缩。这一层优先复用现成的编排框架,评测台负责度量其真实收益。

## 贡献机会

- 新后端适配(实现回放后端接口,接入 vLLM 之外的引擎)。
- 新负载画像 / 数据集 split(见[负载画像](workload-profiles.md))。
- 新优化策略(KV / 调度 / 投机)作为可替换策略对象,在评测台上做受控对照。
- 评测严谨性工具(无损校验、离线最优 oracle、正确性 gate;见[测试与正确性](testing.md))。

# 测试与正确性

两层:**代码正确性**(没改坏)+ **评测正确性**(测得准)。缺任一,结论都不可信。正确性与确定性是一等约束,不是事后补的。

## L1 · 代码正确性

优化插件(KV 策略 / 调度 / 投机控制器)是否改变了模型输出、是否破坏确定性。判据是**无损**:开优化的输出 == 原生输出。

一等测试(任何优化「完成」前必过):

| 测试 | 判据 |
|---|---|
| **无损 · KV** | 缓存开 vs 全关,贪心(`temperature=0`、固定种子)逐 token 等价 |
| **无损 · MTP** | 投机开 vs 关,贪心逐 token 等价;采样下拒绝采样收敛检验 |
| **确定性** | 相同请求逐字节可复现(batch-invariant kernel + 固定种子) |
| **EPHEMERAL 契约** | draft KV 绝不被卸载 / 缓存(见[投机解码](mtp.md)) |

### 无损校验怎么做

LLM 推理默认就不确定(即便 temperature=0),所以「逐字节相同」不能天真比较,分三步:

1. **先消除引擎自身的非确定性**:非确定性主因不是并发随机,而是缺 batch 不变性(归约顺序随 batch 大小变)。开 batch-invariant kernel + 固定 seed,使输出与 batch 大小 / 顺序无关。先确认基线自身对相同输入逐字节可复现——否则「不一致」分不清是 bug 还是引擎抖动。
2. **KV 复用的无损性**:缓存开的输出 token 序列 == 缓存全关的输出,逐 token 比对。KV 命中是数学等价,理论上应完全一致;任何系统性偏移 = 缓存重建 / 块边界 bug。
3. **投机 / MTP 的无损性**:贪心逐 token 等价(最强、最易判);采样场景用拒绝采样收敛检验(大样本下经验分布 == 目标模型分布)。

### pytest 约定

- `tests/correctness/` — 无损 + 确定性 + EPHEMERAL 契约(最高优先级)。
- `tests/unit/` — 纯函数单测(可不起 GPU)。
- `tests/integration/` — 插件在真实后端加载、跑通、不崩。
- `tests/eval/` — L2 的正确性 gate(见下)作为可执行断言。
- **markers**:`slow`(起 GPU / 端到端)、`lossless`、`determinism`、`eval`。快子集进 pre-commit / pre-push;慢的端到端手动或 CI。

## L2 · 评测正确性清单(每次开跑前)

提炼自[评测指南](evaluation.md)。任一不过 = 结论不可报。

开跑前 gate:

- [ ] **回放保真**:离线命中率 ≈ 实测命中率;块大小对齐。
- [ ] **离线最优 oracle 就位**,作为 LRU→最优的上界标尺(报「弥合差距 %」需有分母)。

负载与基线:

- [ ] **不用随机 token**(破坏复用结构);用真实内容。
- [ ] **受限容量区间**(工作集 > 容量)才测得出策略差异。
- [ ] **真实时间戳 + 重尾流行度 + 联合 SLO 下的 goodput**(非裸吞吐)。
- [ ] **prefill / decode 不混杂**统计;CUDA-graph 与 eager 不串味。

报告口径:

- [ ] **无损校验通过**(L1)作为硬约束,随每个 goodput 数字一起声明。
- [ ] 对标真竞争者 + 离线最优,不只打 LRU。
- [ ] **≥3 种子 + 95% 置信区间互不重叠**;增益按复用距离桶拆,标明集中在哪。
- [ ] 拆出**各优化模块对 goodput 的独立贡献**(对照配置:全关 / 只 KV / 只 MTP / 全开)。

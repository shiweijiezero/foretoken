# 负载画像

评测负载如何构建,以及不同负载类型对 KV 复用与 decode 的不同压法。负载结构直接决定两件事:KV 复用价值的上界(没有复用结构,价值感知无从谈起),以及评测真实性(长度、复用、到达三要素一旦失真,goodput 数据失去意义)。

## 评测负载如何构建:会话重建缝合

真实数据有一个缺口:有真实时序与复用结构的 trace(Mooncake)没有内容;有真实内容的对话集没有时序与并发。Foretoken 把两者缝合,得到同时具备真实复用、真实并发与真实内容的负载。

数据源:

| 角色 | 数据 |
|---|---|
| 会话 / 时序 / 并发结构 | Mooncake 生产 trace(`timestamp` / `input_length` / `output_length` / `hash_ids`) |
| 内容 | 真实多轮对话集 |

方法:

1. **重建会话**:Mooncake 无显式 session id,会话关系由 `hash_ids` 的前缀延续隐式编码。按「去尾满块前缀」的延续链重建会话(`hash_ids` 按 512-token 块滚动累积,尾块不满,下一轮累积会改变其 hash,故须比去尾满块前缀而非完整 `hash_ids`,否则真实多轮被漏判为单轮)。两道防误连:共享前缀须达到一个最小块数(排除仅共享公共系统提示的不同会话);后续轮 timestamp 须严格晚于上一轮(排除并发请求被并入)。
2. **填充内容**:打乱对话池,长会话优先取轮数接近的对话逐轮填入;每轮 prompt 为前 k 轮的累积,timestamp 取自对应的 Mooncake 记录;不预设输出长度,回放给统一 `max_tokens` 上限并自然 EOS。
3. **分 split**:`conversation`(对话)、`mooncake`(混合)、`toolagent`(agent / 工具)三个真实子集各自重建,各保留各自约 1 小时的真实时序,互不串联。

复用关系由内容决定、与缓存块大小无关:真实多轮对话本身即产生会话内累积复用(第 k 轮 prompt 含前 k−1 轮全文,字节一致、逐轮增长)与跨会话系统提示共享,并具备价值分层(系统提示、会话历史、一次性内容)——即价值感知策略的评测对象。

实现见 `data_prepare/`(缝合 / 打包)与 `foretoken/bench/`(回放)。

## 负载类型画像

不同负载把 KV / decode 优化拉向不同极端。若评测只覆盖一类,会系统性高估或低估某项优化。

| 负载 | input | output | 复用结构 | 对优化的压法 |
|---|---|---|---|---|
| **reasoning** | 短(题面) | 极长(思维链,可数千~上万 token) | 几乎无跨请求复用(思维链一次性生成) | 主压 decode:投机解码 / TPOT;几乎压不出 KV 复用 |
| **agentic**(coding / tool-loop) | 大前缀(系统提示 + 工具定义,常 10–20k+)+ 累积历史 | 每轮较短 | 高复用(每轮前缀 = 系统提示 + 历史);但动态工具结果不应缓存 | 主压 KV 复用;价值感知须能降权一次性内容 |
| **多轮对话** | 中等,逐轮增长 | 中等 | 会话内逐轮增长前缀 + 跨会话系统提示 | KV 复用(会话内累积);轮间空闲是缓存误驱逐窗口 |
| **RAG** | 大(多检索 chunk + query) | 中等 | 前缀复用结构性破裂(chunk 热门但每次顺序不同) | 朴素前缀缓存抓不到;需位置无关复用,通常划为 out-of-scope |
| **长上下文** | 极大(长文档) | 中等 | 单大前缀会话内复用;跨会话取决于文档是否共享 | 长 prefill 主导 TTFT;分层缓存(GPU/CPU/SSD)价值显现 |

三条结论:

1. **reasoning 不同于长 chat**:output 长且几乎不可 KV 复用(思维链是一次性的),价值从 KV 复用转移到 decode 阶段(投机解码 + TPOT)。
2. **agentic 是 KV 复用价值最高、也最易被污染的负载**:高命中依赖大前缀,但动态工具结果若被当作前缀缓存会反增延迟——这是价值感知区别于纯前缀缓存的关键场景。
3. **RAG 的复用价值真实存在但被前缀假设阻挡**:不做位置无关复用只能划为 out-of-scope。

## 为什么必须用真实 trace

请求顺序决定缓存命中;时间感知策略(按时间间隔的复用概率、TTL、卸载)依赖绝对时间间隔;真实并发决定瞬时 KV 压力。把「到达 trace + 长度数据集」朴素拼接会显著误判容量。全局泊松到达且不区分会话,无法满足上述任一条件。因此评测负载必须保留真实时间戳、真实长度分布与真实前缀复用结构。

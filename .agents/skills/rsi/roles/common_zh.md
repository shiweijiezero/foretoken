# RSI 团队协作

[English](common.md) | 简体中文

Worker 可以在上一方案评测时准备下一方案，Experimenter 负责运行实验并返回结果，主 Agent 根据这些结果调整方向和资源。相关研究尽量交给同一成员继续，减少重复了解背景的时间。

## 分配完整的问题

开始前，每名成员都应阅读任务、自己的角色说明、相关代码和已有实验记录。主 Agent 提供这些资料的位置，并说明：

- 要回答什么问题，哪些结果和判断已经可以复用；
- 可以修改什么，比较时应保持哪些负载、精度和生成设置；
- 谁负责执行，使用哪个工作区、部署、节点和资源配额，结果保存在哪里；
- 还有多少时间，哪些后续工作可以直接继续，什么变化需要重新协调。

成员在这个范围内自主推进，不必每跑一条命令都等待主 Agent。首次交流时说明准备采用的参考方案和对照，便于及早发现理解偏差。需要更多资源、修改共享环境或改变对照条件时，再交主 Agent 协调。

## 分开候选准备与评测

由不同成员准备和执行方案时，把两项工作记为有依赖关系的任务。Worker 交付可复现的代码版本、改动说明、参考结果、负载和执行要求，Experimenter 据此开始评测。交付的版本在排队和运行期间保持不变；后续开发使用另一工作区，或另行保存待测版本。

从同一份任务记录查看准备中、等待评测和执行中的候选数量，分别安排准备和评测的并发。候选准备较慢、评测资源经常空闲时，可以适当提前准备；等待评测的方案过多时，减少新准备，先分析已有结果或完善仍在开发的方案。根据实际耗时和剩余预算调整安排，新证据使某个方案不再值得评测时，记录原因并更新优先级。

有原生任务工具时使用其中的负责人、依赖和完成状态。只有工具支持原子认领、主 Agent 也已分配所需资源时，成员才自行接手就绪任务；否则由主 Agent 指派。没有任务工具时，在实验总览中记录分配及进展。

## 协调资源与运行环境

每个部署由一名成员负责执行和清理。主 Agent 在用户授权内安排资源，并统一处理共享控制面、CRD、驱动和平台安装的变更。代码写入也应明确到工作区、文件或章节，避免两名成员同时修改同一内容。

模型负载使用 Kubernetes 的资源 requests、limits 和设备插件。安排容量时，还要为构建、准备任务和评测客户端留出资源。不同 namespace 和缓存目录可以避免数据相互覆盖，但同一节点上的 CPU、存储和网络仍可能相互影响。最终对照需要无竞争环境时，由相关成员确认其他负载已停止，再开始测量。

负责人可以在原分配内连续运行下一候选。进程和服务停止，或接收方确认交接后，资源才交给其他任务使用。SSH 断开后先查看原作业的状态，避免重复启动。

## 随实验返回结果

固定的负载组合和重复测量交给现有 sweep 连续执行。远端作业使用任务专属会话或已有任务管理器，保存日志和实际退出状态。查看已保存的 benchmark 结果，分别判断测量是否结束、请求是否成功，以及结果是否满足任务要求。

新结果直接发给需要它的成员，说明结果位置、资源状态、下一步，以及需要协调的事项。主 Agent 收到完成或依赖变化后，先安排已就绪工作，再继续自己的研究。成员遇到局部阻塞时，继续推进范围内不受影响的工作。

Experimenter 维护所负责的迭代记录，主 Agent 指定一名作者更新总览和报告。摘要链接原始记录；输入和条件没有变化时，继续使用已经核验的结果。具体写法见[实验记录手册](../../../../rsi-playbooks/experiment-records_zh.md)。

## 独立复核结论

决定保留方案前，请另一名没有参与该方案实现和运行的成员检查结果。审查时查看实际代码、运行配置和原始数据，确认改动确实生效，核对精度、负载、输出设置和资源分配，再判断失败请求、缓存、预热或其他负载是否影响了性能比较。只有具体疑问尚未解决时，才安排补测。

记录中分别写清开发者的解释、审查者的判断和主 Agent 的决定。Experimenter 负责整理这些内容，最终是否保留或集成由主 Agent 决定。

## 交接与恢复

一项工作结束时，说明结论、结果位置、剩余问题，以及哪些进程和资源仍在使用。后续工作已在原分配内时可以继续，否则向主 Agent 提出建议。恢复任务时，先核对已有记录、作业和成员状态，沿用原预算与已经完成的结果。

用户要求暂停、停止，或任务到期时，停止安排新实验，由负责人停止或交接作业并保存结果。GPU 采集器的 deadline 只停止采集，其他作业也需要各自停止。

有效工作人数按实际开展任务的 Worker、Experimenter 和 Advisor 统计，每人只计一次。主 Agent、等待、阻塞和已完成的成员不计入；证据不足的时段注明未知。

# Record Templates

English | [简体中文](README_zh.md)

Use these templates as references for notes under `results/`, selecting the sections relevant to the experiment:

- [Experiment notes](experiment-template.md): overall goal, scope, comparison method, and findings across iterations.
- [Iteration notes](iteration-template.md): analysis, hypothesis, design, implementation, measurements, and decisions for one approach.

Update the same iteration note when adding runs of an existing approach. At the end of each iteration, incorporate new findings into the experiment summary. Follow the [completion steps](../guidance/experiments.md#at-the-end-of-each-iteration).

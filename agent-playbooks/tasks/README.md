# Optimization Tasks

English | [简体中文](README_zh.md)

Task playbooks describe how to investigate an optimization goal, design and deploy changes, and evaluate their effects. The scope can be routing, the inference engine, or the whole system.

No task-specific playbooks are available yet. Start with the [general steps](../README.md#steps) and [experiment guidance](../guidance/experiments.md).

When adding a task playbook, state the optimization goal and change scope. Link the relevant code and references, provide deployment and evaluation steps, and explain how to judge results. Link shared recording methods from the experiment guide and add only task-specific checks here.

After each iteration, follow the [completion steps](../guidance/experiments.md#at-the-end-of-each-iteration) for records, code, and temporary resources.

# 优化任务

[English](README.md) | 简体中文

任务手册围绕具体优化目标，说明如何调查问题、设计方案、部署改动和验证效果。范围可以是路由、推理引擎等部分，也可以覆盖整个系统。

目前尚无具体任务手册，可先按[通用步骤](../README_zh.md#使用步骤)开展工作，并参考[实验指导](../guidance/experiments_zh.md)。

补充具体任务手册时，写清优化目标和可改动范围，给出相关代码与参考入口、部署和评测步骤，以及判断结果的方法。共用的记录方法链接到实验指导，任务中只补充该场景特有的检查。

每轮执行完任务后，按[收尾步骤](../guidance/experiments_zh.md#每轮结束后)处理记录、代码和临时资源。

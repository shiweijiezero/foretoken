# Qwen 解码速度优化

[English](qwen-decode.md) | 简体中文

## 目标

提高 Qwen3.5-35B-A3B BF16 在单请求负载下的解码速度，同时保持回答质量。主要比较每输出 token 耗时（TPOT）和输出 token/s。

## 范围与约束

优化范围不限定组件，由 Agent 分析并设计方案，可涉及引擎、调度、算子、通信和服务配置。

使用提供的部署环境和目标负载；未指定负载时，由 Agent 选择并说明依据。前后比较保持模型版本、精度、思考模式和输入输出长度一致。若改变其中某项，将其作为独立方案说明，不与实现优化混为一个结论。

## 执行与交付

Agent 按[通用流程](../README_zh.md#使用步骤)完成调查、设计、部署和迭代，从[评测命令](../../benchmarks/docs/recipes_zh.md)中选择所需测试。修改前后分别测量速度和回答质量，依据瓶颈决定是否进行性能剖析。

实验记录保存在 `results/decode-speed/qwen35-bf16/`，按[记录要求](../templates/experiments_zh.md)由 Agent 补充每次运行的解释和每轮结论。交付可复现的改动、速度与质量对比，以及保留、回退或继续尝试的决定。

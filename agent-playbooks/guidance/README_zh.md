# 参考与方法

[English](README.md) | 简体中文

准备实验时，先阅读下面的记录方法，确定说明和运行证据的保存位置。分析过程中使用的研究资料，以及验证后可复用的测量和诊断方法，也归入本目录。

- [实验记录](experiments_zh.md)：组织迭代与运行、保留证据和记录耗时。每轮完成后按其中的[收尾步骤](experiments_zh.md#每轮结束后)更新结论、处理改动和资源。

补充方法时说明解决的问题、适用条件、操作方式和验证依据；单次实验数据留在 `results/`，在指导中引用。

具体优化目标的操作步骤见[任务手册](../tasks/README_zh.md)，编写说明时可参考[记录模板](../templates/README_zh.md)。

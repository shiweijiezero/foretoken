# 智能体任务手册

[English](README.md) | 简体中文

面向 Agent 的 Foretoken 推理系统优化任务手册。

## 为什么需要这套手册

Foretoken 的优化通常同时涉及源码、部署、工作负载设计、运行时行为和可观测性。智能体可以很快写出看似合理的实现，但一项有价值的改动还必须满足正确的职责边界，经过真实执行路径验证，并用运行证据说明结果及其原因。

这套手册把上述工作组织成可重复的路径：从任务目标出发，关联项目背景、参考资料、允许的改动范围、执行步骤、验证方法、问题定位和证据要求。

## 使用方式

1. 选择与目标相符的优化任务。
2. 阅读 `common/` 中的通用规则。
3. 阅读 `guidance/` 中相关的架构和验证材料。
4. 按照 `tasks/` 下的任务手册执行。
5. 修改前检查当前源码和配置。
6. 执行手册规定的真实部署、工作负载和观测流程。
7. 记录结果，包括未取得收益的结果以及归因仍有限的部分。

开发者负责选择任务和审查改动。Agent 在规定边界内完成调查、实现、执行和分析。

## 任务手册应包含什么

每份任务手册都应说明：

- 任务目标和成功标准；
- 职责边界和相关代码入口；
- 参考资料和需要了解的项目背景；
- 允许的改动范围和非目标；
- 部署与实验步骤；
- 验证、观测和问题定位方法；
- 行为真实性和因果归因检查；
- 必须保留的证据及后续知识沉淀。

## 目录结构

- `common/`：所有任务共用的规则；
- `guidance/`：架构、代码入口、参考资料和验证指导；
- `tasks/`：具体优化任务的手册。

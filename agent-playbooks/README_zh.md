# 推理系统优化任务手册

[English](README.md) | 简体中文

用于改进 Foretoken 推理系统的任务手册。

## 为什么需要这套手册

推理优化通常同时涉及源码、部署、工作负载设计、运行时行为和可观测性。相关代码、命令、指标和示例分散在不同位置，容易在迭代过程中遗漏。

每份手册都为一类优化任务提供清晰的起点、需要了解的背景、执行步骤和结果检查方式，帮助更快地从优化想法走到实测结果。

## 使用方式

1. 选择与目标相符的优化任务。
2. 阅读 `common/` 中的通用内容，以及 `guidance/` 中的相关指导。
3. 检查当前源码和配置。
4. 按照现有源码流程完成修改和部署。
5. 执行任务手册规定的工作负载、benchmark 或 profile。
6. 与参考结果进行比较，并记录发生了什么变化。

## 任务手册应包含什么

每份任务手册都应说明：

- 任务目标和成功标准；
- 所属职责和相关代码入口；
- 参考资料和项目背景；
- 改动范围和非目标；
- 部署与实验步骤；
- 验证、观测和问题定位方法；
- 结果解释和后续工作。

## 目录结构

- `common/`：所有任务共用的内容；
- `guidance/`：架构、代码入口、参考资料和验证指导；
- `tasks/`：具体优化任务的手册。
